사이트의 대부분 이미지와 링크는 site-config.js 한 파일에서 관리합니다.

HAPPY 대표 이미지

assets/images/happy-project-main.png 파일을 같은 이름으로 교체하거나 images.happyMain 값을 수정하세요.

은유제작소 로고

assets/logo/eunyu-logo.svg 파일을 교체하거나 brand.logo 값을 수정하세요.

외부 이미지 링크 예시
happyMain: "https://example.com/my-happy-image.jpg"

Instagram / YouTube / GitHub
site-config.js → links에서 # 부분을 실제 주소로 바꾸세요.
